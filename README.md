## 🔎 Overview

Every Telegram user, channel, group, and bot possesses a permanent numerical identifier that remains unchanged even if the `@username` or display name is updated.

**`@IDNumericbot`** allows you to retrieve these unique numeric IDs in seconds. Perfect for developers, group administrators, and security checks.

---

## ⚡ Key Features

- 🆔 **Instant User ID Extraction:** Discover the permanent numerical ID of any Telegram profile.
- 💬 **Group & Channel Chat ID:** Easily fetch the internal Chat ID of channels and supergroups.
- 📩 **Forward-to-Check:** Simply forward a message from any contact to reveal their hidden ID.
- ⏱️ **Account Age Indicator:** Get an estimated age of Telegram accounts based on ID generation sequences.
- 🚀 **100% Free & Fast:** Immediate response time with no registration required.

## 💡 Usage Examples

- **Get Your Own ID:** Type `/start` or `/me` in the bot chat.
- **Get Another Person's ID:** Forward any text/media message sent by that user to the bot.
- **Get Group / Channel ID:** Forward a post from the channel or add the bot to the group.
